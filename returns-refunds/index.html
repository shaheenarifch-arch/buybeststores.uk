Returns and Refunds

SmartTech handles returns according to the type of transaction and applicable UK consumer rights. The process for a SmartTech-owned online product is different from a repair service, a device sold to SmartTech or a Smart Fitness purchase completed on an external retailer website. Customers should keep order confirmations, packaging, accessories and tracking evidence. A blanket “no returns after opening” rule is not used to remove statutory rights.

Request Return SupportContact SmartTech

How the service works

  1. Contact support with the order, repair or valuation reference.
  2. Explain whether the request concerns cancellation, damage, fault or incorrect goods.
  3. Follow the supplied return or collection instructions.
  4. Package the product securely with the agreed accessories.
  5. SmartTech inspects the return and communicates the outcome.
  6. Approved refunds return to the original payment method unless lawfully agreed otherwise.

External partner returns

When a customer clicks View Product and completes payment on the external retailer website, the retailer is the seller for that transaction. The retailer handles cancellation, return shipping, refunds and warranty support. SmartTech can identify the sponsored link used but cannot process a retailer refund. Repair-service cancellations may involve a proportionate charge where the customer expressly requested work to begin and diagnostic or repair work has already been performed.
